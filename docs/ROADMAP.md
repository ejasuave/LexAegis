# Roadmap

The one adoption and post-hackathon roadmap is [`adoption/ROADMAP.md`](./adoption/ROADMAP.md): a **plan,
not a commitment**, in 30, 60 and 90 day phases measured from a start date that is **NOT YET SET**. This
page holds no separate commitments, so nothing here can conflict with it.

What is built today, and what is explicitly not, is recorded in [`DEPLOYMENTS.md`](./DEPLOYMENTS.md),
[`QUICKSTART.md`](./QUICKSTART.md) and [`integration-trials.md`](./integration-trials.md). Traction is
counted only from [`adoption/traction-log.md`](./adoption/traction-log.md), which is empty.
